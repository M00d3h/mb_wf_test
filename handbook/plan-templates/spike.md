# Spike

**Use for:** a time-boxed question that blocks planning or a decision.
**Usually needs:** nothing.
**Produces:** `finding.md`, and any work items the answer implies

## Steps

- [ ] Write the question and the time box in the plan's goal.
- [ ] Investigate. Any code is evidence only and isn't merged.
- [ ] Write `finding.md`: what you found, what you ruled out, what you'd do next.
- [ ] Create items for any work the answer implies.
- [ ] Close. A spike that runs out of time still closes with what it learned.
