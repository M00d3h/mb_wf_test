# Backlog

Work we've decided not to do yet. One file per item, `NNNN-<slug>.md` where `NNNN` is the work item
that raised it, copied from [`handbook/scaffolds/backlog-item.md`](../handbook/scaffolds/backlog-item.md).

Items arrive when a work item closes with deferred work, when a design records a path not taken, or
whenever anyone adds one. They leave when a work item takes them on, or when backlog triage drops
them. Either way the file gets a final state and moves to `archive/YYYY/` during the next backlog
triage. Nothing is deleted.
